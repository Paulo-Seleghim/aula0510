# EduConnect Pro
Sistema escolar demonstrativo desenvolvido com Next.js App Router.

## Funcionalidades
- Landing page profissional
- Login demonstrativo
- Dashboard executivo
- Alunos
- Professores
- Turmas
- Notas
- Frequência
- Calendário
- Avisos
- Configurações
- Busca, filtros visuais, indicadores e tabelas
- Layout responsivo

## Executar
npm install
npm run dev

Acesse http://localhost:3000
